### Project Overview
This project presents the schematic design and two-layer PCB implementation of an LDR-based automatic night lamp. The circuit uses a light-dependent resistor to detect ambient illumination and a transistor switching circuit to control an LED automatically.

### Features
- Automatic light-dependent switching
- LDR-based ambient light detection
- Transistor-based switching
- Schematic capture
- PCB layout design
- Two copper layers: F.Cu and B.Cu
- Design Rule Check (DRC)
- 3D PCB visualization
