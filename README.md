## Task 7 Submission: ESP32-CAM TinyML Hand Classifier Carrier Board

**Intern:** Arya Sharan  
**EDA Tool:** eSim 2.5  
**Internship:** eSim Semester Long Internship — Autumn 2026

### Project

A dual-layer PCB designed in eSim 2.5 as a production-grade carrier board for the ESP32-CAM module running TinyML hand-sign classification. Features an AMS1117-3.3V power regulator, RF antenna keepout zone, hardware RESET/FLASH buttons, and I²C expansion headers.

📂 **Project files:** [`ESP32_TinyML_Hand_Classifier/`](./ESP32_TinyML_Hand_Classifier/)

### Highlights

| Feature | Detail |
|---|---|
| Board Layers | 2 (F.Cu + B.Cu) |
| Power Traces | 0.8 mm |
| Signal Traces | 0.4 mm |
| DRC Result | **0 Errors** ✅ |
