# TP4056-Based Lithium-Ion Battery Charger PCB

## Project Overview
This project focuses on designing a PCB for a TP4056-based lithium-ion battery charging circuit as part of the FOSSEE eSim Semester Long Internship – Autumn 2026, Task 7.

## Project Objective
To design and document a PCB implementation of a TP4056-based single-cell lithium-ion battery charger.

- KiCad
- PCB Editor
