# STM32-Based Smart Environmental Monitoring and Control PCB

## Overview

This project is an STM32-based four-layer PCB designed for **smart environmental monitoring and control in aquaculture systems**. The board integrates the microcontroller, environmental sensor interfaces, power management, communication interfaces, and control circuitry required for monitoring and managing aquaculture conditions.

## PCB Design

The board is designed as a **four-layer PCB** with the following stack-up:

* **Layer 1 (Top):** Components and signal routing
* **Layer 2:** Dedicated GND plane
* **Layer 3:** Dedicated +3.3 V power plane
* **Layer 4 (Bottom):** Components and signal routing

The four-layer stack-up provides dedicated power and ground planes while allowing organized signal routing and improved power distribution. Component placement and routing were planned to maintain clear separation between sensitive environmental sensing signals and higher-current control paths.

## Application

The PCB is intended for aquaculture applications where environmental parameters can be monitored and controlled to help maintain suitable conditions for aquatic organisms. The STM32-based system provides the processing and control required to interface with sensors and connected control devices.
