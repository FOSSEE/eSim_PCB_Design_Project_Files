1. Executive Project Overview

This project demonstrates the complete end-to-end electronic design automation (EDA) workflow for a high-performance, industrial-grade Intelligent USB-C Power Delivery (PD 3.0) Dynamic Sink Trigger and High-Speed Smart eFuse Protection Board. The system operates as a programmable universal power interface, enabling electronic systems to dynamically negotiate any standard USB-C power profile (5V, 9V, 12V, 15V, or 20V at up to 5A / 100W) using an onboard CH224K hardware state controller.

Simultaneously, the board incorporates an autonomous solid-state Smart eFuse circuit utilizing an active P-channel power MOSFET (AO4407A, -30V, -12A, ultra-low RDS(on) = 11mΩ) paired with a high-speed precision differential comparator (LM393) and a high-power low-side current sense resistor (0.05Ω, 2W). The trip threshold is user-tunable via a precision 10kΩ multi-turn potentiometer, providing sub-microsecond fault response times compared to sluggish thermal fuses or mechanical circuit breakers.

Key Technical Specifications:
  • Input Voltage Range: 5.0V – 20.0V DC (Standard USB PD 3.0 negotiated via CC1/CC2 lines)
  • Continuous Load Capacity: Up to 5.0A continuous (100W peak power transfer)
  • Overcurrent Protection: Active Solid-State Smart eFuse with adjustable trip current (0.5A – 4.0A)
  • Fault Response Time: < 5 microseconds (Solid-State P-MOSFET gate discharge)
  • Telemetry / Indicators: Green LED (Normal Power Output Active), Red LED (Fault / Overcurrent Tripped)
  • PCB Architecture: 2-Layer FR-4 (1.6mm thickness, 1 oz copper) with continuous ground flood planes

2. Circuit Subsystems & Working Principle

The circuit is structured into eight coordinated subsystems:

  1. USB-C 16-Pin Receptacle Interface (J1): Reversible USB Type-C receptacle with symmetrical VBUS rails and dual Configuration Channel (CC1, CC2) pull-down resistors (5.1kΩ) for automatic Cable-Detect and Sink advertisement.
  2. Hardware PD State Controller (CH224K - U1): Dedicated hardware sink trigger that decodes BMC (Biphase Mark Coding) packet protocols and negotiates voltage contracts based on 3-bit DIP switch logic (CFG1, CFG2, CFG3).
  3. Transient Overvoltage Suppression: Bidirectional SMBJ20CA TVS diode immediately across VBUS and GND to clamp inductive spikes, ESD discharges, and cable hot-plug transients up to ±30kV.
  4. High-Side Power Switch (AO4407A - Q1): Logic-driven P-Channel MOSFET providing high-side power delivery with ultra-low conduction losses.
  5. Precision Current Sense Resistor (0.05Ω 2W): Low-inductance alloy resistor creating an accurate current-proportional differential millivolt signal.
  6. Fast Comparator & Voltage Reference (LM393 - U2): High-speed differential voltage comparator monitoring the current sense voltage against an adjustable reference established by a 10kΩ potentiometer.
  7. Visual Status Feedback: Dual SMD LED telemetry providing immediate visual status (Green = Active/Safe, Red = Trip/Fault).
  8. Heavy-Duty Output Terminal Block (J2): 5.08mm screw terminal block for reliable external load connection.

5. PCB Layout & Routing Methodology

The physical PCB layout was designed on a standard 2-Layer FR-4 substrate with 1.6mm thickness and 1 oz (35µm) copper. Key engineering principles applied during layout include:

  • Linear Power Flow Architecture: A direct left-to-right power progression from Input (USB-C J1) → TVS → P-MOSFET (AO4407A) → Current Sense Resistor → Output Terminal Block (J2), minimizing parasitic trace loop inductance.
  • Power Trace Sizing: Main VBUS and VOUT conductor tracks were routed with wide geometries (1.5mm – 2.0mm) and poured copper polygon fills capable of conducting 5A continuously with < 10°C thermal rise.
  • Dual Solid Ground Planes: Both Top Layer (`F.Cu`) and Bottom Layer (`B.Cu`) feature continuous copper pours assigned to net `GND`. Stitching vias were placed throughout to interconnect isolated copper islands and provide low-impedance return paths.
  • Thermal Relief Strategy: All through-hole and SMT ground pads feature thermal relief spoke connections to prevent cold solder joints while maintaining solid thermal/electrical grounding.
  • Signal Integrity: 45-degree mitered trace corners were strictly used throughout to eliminate sharp right-angle reflections and acid traps.

8. Design Considerations & Engineering Best Practices

  • Current Sensing Dissipation: At a peak 3A continuous load, power dissipation in the 0.05Ω sense resistor is P = I2R = (3)2 × 0.05 = 0.45W. The 2512 package is rated for 2.0W, giving a safety factor > 4.4×.
  • MOSFET Thermal Margin: The AO4407A features RDS(on) ≤ 11mΩ. Conduction loss at 3A is P = (3)2 × 0.011 = 0.099W (less than 100mW), eliminating the need for bulky external heatsinks.
  • Noise Immunity: The comparator reference divider incorporates decoupling capacitors (0.1µF) to prevent nuisance tripping during sudden USB PD voltage negotiation step transitions.
