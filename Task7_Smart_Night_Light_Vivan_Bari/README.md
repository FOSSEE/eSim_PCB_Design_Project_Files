# Smart Automatic Night Light Controller

FOSSEE Winter Internship 2026 — Screening Task 7

Applicant: Vivan Bari

A two-layer PCB designed using eSim 2.6 and KiCad 9.0.3.

The circuit uses an LDR and an LM393 comparator to control an LED through a 2N7000 MOSFET.
